# Architecture decision records

Capture only **hard-to-reverse**, **surprising**, or **trade-off-laden**
decisions here. Per-feature scope decisions live in the relevant
`docs/specs/<slug>.md`.

File naming: `NNNN-<kebab-slug>.md`, numbered from 0001. Don't reuse numbers,
even for superseded ADRs.

Template sections:

- **Status** — proposed | accepted | superseded by NNNN
- **Date**
- **Context**
- **Decision**
- **Consequences**
- **Alternatives considered**
